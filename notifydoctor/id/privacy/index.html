Notify Doctor dikembangkan oleh Andrea Ferendeles dan membantu memahami pengaturan pengiriman notifikasi Android.

Data yang diproses di perangkat

Jika Anda secara eksplisit mengaktifkan akses notifikasi Android, Notify Doctor hanya memproses metadata diagnostik secara lokal: paket dan nama aplikasi sumber, waktu, pengenal saluran, dan status pengiriman. Aplikasi tidak menyimpan judul, teks pesan, orang, gambar, atau konten notifikasi lain. Aplikasi tidak menggunakan layanan Aksesibilitas.

Penyimpanan, laporan, dan penghapusan

Metadata peristiwa mentah dihapus otomatis setelah 24 jam. Hitungan harian agregat dapat tetap di perangkat untuk menunjukkan tren. Laporan dan ekspor hanya berisi informasi perangkat, nama aplikasi, temuan, dan tingkat keyakinan; tidak pernah konten notifikasi. Anda dapat menghapus semua data aplikasi dari Setelan Android kapan saja.

Berbagi, iklan, dan pembelian

Data diagnostik tidak dikirim ke pengembang atau dijual. Pengguna Free dapat melihat Google Mobile Ads setelah persetujuan Google UMP; pengguna Pro tidak melihat iklan. Pilihan privasi iklan dapat ditinjau di aplikasi. Pembelian Pro satu kali diproses oleh Google Play; data pembayaran ditangani sesuai kebijakan Google.

Pilihan dan keamanan Anda

Akses pendengar notifikasi bersifat opsional dan dapat dicabut di Setelan Android; tujuannya dijelaskan sebelum diaktifkan. Izin notifikasi hanya untuk peringatan panduan/status aplikasi sendiri. Data tetap di perangkat. Kami memakai perlindungan platform dan HTTPS saat komunikasi dengan layanan Google diperlukan. Data diagnostik tidak ditransfer secara internasional karena tidak diunggah.

Kontak dan penggunaan internasional

Untuk pertanyaan privasi, email aferende@gmail.com. Layanan Google tunduk pada kebijakan privasi Google. Kebijakan ini dapat diperbarui jika praktik data atau layanan berubah.
